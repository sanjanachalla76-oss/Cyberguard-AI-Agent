# CyberGuard AI - SOC Analyst Agent

## Overview

CyberGuard AI is a cybersecurity-focused AI agent that assists Security Operations Center (SOC) analysts.

## Tools

### 1. Log Analyzer Tool

Analyzes logs and detects suspicious activity such as brute-force attacks.

### 2. Threat Intelligence Tool

Checks whether an IP address is known to be malicious.

### 3. Incident Response Tool

Provides recommended actions for handling security incidents.

## How to Run

1. Open a terminal
2. Navigate to the project folder
3. Run:

```bash
python agent.py
```

## Example Use Cases

* Detect brute-force attacks
* Analyze suspicious IP addresses
* Generate incident response recommendations
